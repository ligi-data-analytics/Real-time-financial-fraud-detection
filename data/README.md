# Data

This folder contains documentation related to the PaySim financial transaction dataset.

The PaySim dataset is not stored directly in this repository because of its large size.

## Dataset

Source:
PaySim Synthetic Financial Dataset

The dataset contains simulated mobile money transactions with information such as:

- Transaction type
- Transaction amount
- Sender balance
- Receiver balance
- Fraud indicator
- Transaction step

The dataset will be used for exploratory analysis, feature engineering, machine learning, and real-time fraud detection.
